Emplacement des bruitages BUB (optionnel), au format des autres jeux AKA.
Fichiers d'origine possibles (a convertir en WAV mono 44100 depuis le jeu
original https://gitlab.com/smogheap/bub, dossier sound/) :
  SLURP.wav  (aspiration bulle/cle)
  PLOP.wav   (pose d'une bulle)
  STEP.wav   (pas)
  CLIMB.wav  (echelle)
  FLAG.wav   (drapeau / niveau reussi)
  UNLOCK.wav (porte ouverte)
  OOF.wav    (blocage)
  RESTART.wav
Noms 8.3 obligatoires. Le code audio n'est pas encore branche cote firmware.
